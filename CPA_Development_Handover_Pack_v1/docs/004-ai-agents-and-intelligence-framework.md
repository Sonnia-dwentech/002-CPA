# 004 — AI Agents & Intelligence Framework

**DWEN TECH LTD | CPA DEVELOPMENT HANDOVER PACK v1.0**  
**Classification:** Confidential – Internal  
**Status:** Proposed baseline; CEO approval and Justice technical review pending  
**Date:** 17 October 2026

## Design stance

Begin with a single orchestrated workflow using specialised prompts/services. Do not create independently autonomous agents merely to mimic a research lab. Add agent separation only when measurable quality, security or maintenance benefits justify it.

## Agent/function catalogue

Discovery Researcher: source-based problem discovery. Market Analyst: demand, market scope, pricing evidence. Competitor Analyst: alternatives and differentiation. Academic Analyst: findings and licences. Solution Architect: workflows and feasible features. Feasibility Reviewer: technical constraints. Commercial Modeller: assumptions and scenarios. Risk Reviewer: privacy, regulatory and operational risks. Critical Challenger: adversarial critique and disconfirming evidence. Evidence Auditor: citation verification and uncertainty. Report Composer: coherent dossiers and investor outputs.

## Execution contract

Every run has requestor, jurisdiction, objective, authorised tools, input source list, budget, timeout, outputs and human-review status. Sequence: define question → collect sources → validate provenance → extract claims → compare/counter-check → score → draft report → audit citations → save version → human review.

## Research evidence policy

Every externally derived material claim has URL/DOI, title, publisher, publication/access date, source type, licence if applicable, and quotation/summary boundaries. Missing evidence labelled as hypothesis. Source collection must obey robots, terms, rate limits, copyright and permissions.

## Global scan semantics

A Global scan is a multi-region research plan, not omniscience. Record which countries, languages, sectors, feeds and time windows were actually covered. Show gaps, source bias and coverage limitations.

## Structured opportunity output

problem_statement; geography; impacted_users; severity_score; demand_evidence[]; competitors[]; proposed_solution; ai_advantage; pricing_hypotheses; market_estimate_assumptions; feasibility; risks[]; source_refs[]; evidence_grade; scoring_breakdown; recommendation; validation_experiments[]; human_decision.

## Evaluation and safeguards

Test citation accuracy, groundedness, relevance, contradiction detection, prompt injection resistance, data leakage, JSON schema adherence, refusal/error behaviour and cost. Use curated fixtures for OnCallX and hypothetical cases. Human approvals for external publication and investment decisions.

## Cost and monitoring

Set per-run budget, per-user quotas, monthly spending alerts, max source count, retry ceiling and cancellation. Log model, latency, input/output tokens, cost estimate, quality checks and exceptions without leaking sensitive prompts.
