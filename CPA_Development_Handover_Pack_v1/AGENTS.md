# CPA Repository Working Rules

This repository belongs to Dwen Tech Ltd. The development team consists of Justice (technical lead) and a **human assistant developer**. Any AI coding tools are optional aids, not authorised approvers.

Read `docs/handover-pack-v1/001-*` through `010-*` before implementation. Only implement approved GitHub issues in the current phase. Use feature branches from `develop`; submit PRs; do not bypass review.

Never commit API keys, client records, passwords, access tokens or restricted research text. Never fabricate research sources, evidence or financial figures. Separate hypotheses from verified facts. Write tests, document changes, follow RBAC and least privilege, and escalate ambiguity to Justice.

Initial milestone: secure application foundation, then idea-to-evidence-labelled-dossier MVP. Do not build autonomous global scanning before approval.
